GENERAL
space - projection / setup mode   |   g - show/hide gui (hide it to edit with the mouse)
f - fullscreen   |   w / SHIFT-w - window background from camera / image file   |   h - this help   |   CTRL-q - quit
p / o - start / stop projection   |   r - resync videos, slideshows and transitions
CTRL-s - save project to the startup file   |   F1..F4 or [ ] - gui pages

SURFACES (setup mode)
a - add   |   CTRL-x - delete   |   CTRL-SHIFT-x - delete all   |   < > - previous / next
+ - - raise / lower layer (gui hidden)   |   q - fill window   |   # $ - rotate 5 degrees
CTRL-c / CTRL-v - copy / paste surface settings   |   * - swap camera RGBA/BGRA

CORNERS (setup mode, gui hidden, not in mask or deform mode)
drag a corner; drag the center to move; drag the handle right of the center to rotate
SHIFT-drag a corner - scale   |   CTRL-arrow - select corner   |   arrow / SHIFT-arrow - nudge 1 / 10 px

MASK (m - toggle; setup mode, gui hidden)
click - add point   |   drag - move point   |   d - delete point under mouse
F2 - delete last point   |   c - clear mask

DEFORM (b - toggle; setup mode, gui hidden; enable "Use bezier" or "Use grid" on page 2)
drag - move a bezier / grid control point

TIMELINE (while shown, only these keys and F4 / CTRL-q work)
F10 - show/hide timeline   |   space - play/pause   |   F12 - play/stop
F9 - BPM grid   |   F11 - show/hide stage
